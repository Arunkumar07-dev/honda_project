# Honda-Inspired Frontend Website

Educational frontend project built with HTML, Tailwind CSS and JavaScript.

## Features
- Responsive mobile-first design
- Automotive landing page
- Vehicle model cards and filtering
- Vehicle details page
- Technology and About pages
- Interactive gallery/lightbox
- Test-drive/contact form
- Responsive mobile navigation

## Run

```bash
npm install
npm run dev
```

For production:

```bash
npm run build
```

## Note

This is an independent educational/portfolio concept inspired by automotive website patterns. It is not an official Honda website. Replace placeholder images with images you are licensed to use.


## UI recreation
The original HTML page structure, navigation links, model filtering, gallery lightbox, mobile menu, and contact-form behavior were preserved. The visual layer was redesigned to match the premium dark/red automotive UI reference. The supplied ZIP did not contain actual vehicle image files, so local educational vehicle artwork was added to `assets/images/`.
